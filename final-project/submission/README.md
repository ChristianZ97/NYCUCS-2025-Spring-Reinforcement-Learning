# Private grading provenance

The exact grading and presentation artifacts are intentionally not copied into
this portfolio-facing tree. They remain byte-for-byte recoverable from the
private `legacy` branch at exact pre-curation commit
`14c78350cc80c564ce9b1f7abedb4c44075c0626`.

The final report contains contributor names, institutional affiliations, and
email addresses. Other bundles contain feedback, course-owned guidelines,
identity-bearing filenames, and macOS metadata. The canonical files in `src/`
are cleaned derivatives and must not be described as exact submissions.
